# Erişilebilirlik

- **Focus halkası** tüm etkileşimli öğelerde aynıdır:
  `outline: var(--lg-focus-ring-width) solid var(--lg-accent)` +
  `outline-offset: var(--lg-focus-ring-offset)`, yalnız `:focus-visible`.
- İkon-tek butonlarda `label` prop'u zorunludur (`aria-label` + `title`).
- Kalıcı durumlar ARIA'ya yansır: `aria-pressed`, `aria-selected`, `aria-current`,
  `aria-expanded`, `role="tablist|tab|tabpanel"`, lightbox `role="dialog"` + `aria-modal`.
- **Hedef seviye WCAG 2.2 AAA.** Karşılanan kriterler ve karşılıkları:

  | Kriter | Karşılık |
  |---|---|
  | 1.4.6 Contrast (Enhanced) | Palet 7:1'e kalibre — tonlu `color-mix` zeminleri dahil (bkz. Token'lar) |
  | 1.4.8 Visual Presentation | Gövde metni `--lg-measure` (≈77 karakter), satır aralığı ≥ 1.5 |
  | 2.5.5 Target Size (Enhanced) | Dokunmatikte kontrol tabanı 44px. İmleçli cihazda görünür ölçek 36–40px'e iner: orada karşılanan seviye **AA 2.5.8** (24px tabanı) — bkz. Token'lar → Kontrol yükseklikleri |
  | 2.4.12 Focus Not Obscured (Enhanced) | Odak, yüzen header/dock altında kalmaz (`scroll-margin-block`) |

  Amber koyu temada `#E9B179`'a açılır, üstü koyu kahve metin alır.

  Denetim otomatiktir ama tek başına yetmez: `axe-core` `color-contrast-enhanced`
  kuralını ölçer, **2.5.5 ve 1.4.8'i ölçmez**. Dokunma hedefi doğrulaması
  `elementFromPoint` ile gerçek tıklanabilir alan taranarak yapılır —
  `getBoundingClientRect()` görünmez `::after` genişletmelerini görmez.
- `prefers-reduced-transparency` → cam donuklaşır (refraction kapanır, blur kalır).
- `prefers-reduced-motion` → spring/lift animasyonları kapanır; yalnız renk geçişi kalır.

# Motion

Kaynak: `src/motion/presets.ts` + `useGlassPress`.

| Geçiş | Mekanizma | Reduced motion |
|---|---|---|
| Basınç (sıvılaşma + jöle) | spring (`press`, `jelly`) — transform/filter | kapalı |
| Hover lift | CSS `scale` + gölge, 160ms ease-out | scale kapalı |
| Sekme/sidebar seçim geçişi | motion layout (FLIP) | anında |

Kurallar: animasyon yalnız `transform` / `opacity` / `filter` üzerinde (layout
tetiklemez) · kesilebilir (spring) · exit tamamlanmadan DOM kaldırılmaz.

# Responsive

- Breakpoint yerine **yetenek sorguları**: `@media (hover: hover)` hover'ı yalnız
  imleçli cihazlara verir. `@media (pointer: coarse)` kontrol ölçeğini token
  düzeyinde büyütür (36/40 → 44); bileşenler ayrıca yükseltme yapmaz, ölçüyü
  yalnız `--lg-control-*` üzerinden okur.
- Sayfa genişliği ve kenar boşluğu container kademesinden gelir; sayfa kendi
  `max-width`'ini yazmaz (bkz. Token'lar → Sayfa container'ı).
- Genişlik davranışı container'a göre: kartlar `minmax()` grid'de akar,
  thumb şeritleri ve carousel yatay scroll'a düşer (`scrollbar-width: none`).
- Cam yüzeyler büyüdüğünde refraction alan sınırıyla otomatik düz blur'a iner —
  performans responsive'i de tasarımın parçasıdır.
- Safe-area: tam ekran overlay'ler (lightbox) viewport birimleriyle sınırlanır.
